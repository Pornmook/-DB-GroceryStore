This project is part of the Database Systems and System Analysis & Design courses.
The objective of this project is to study and practice system analysis and design by creating and modeling a complete system.

The project covers the following topics:
- System Requirements
- Use Case Diagram
- Use Case Description
- Context Diagram
- Data Flow Diagram (DFD) Level 0
- Entity–Relationship (ER) Diagram
- Database Tables
- Class Diagram
- Activity Diagram
- Data Structure Diagram (DSD)
